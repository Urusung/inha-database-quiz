# inha-database-quiz

인하대 데이터베이스 시험 대비용 정적 퀴즈 페이지입니다. 첫 화면에서는 중간고사/기말고사 개념 퀴즈만 선택할 수 있게 구성했습니다.

## 방향

- 중간고사와 기말고사를 별도 페이지로 분리합니다.
- 문제는 시험 대비 개념 퀴즈 중심으로 구성합니다.
- `index.html`에는 중간고사/기말고사 카드만 노출합니다.

## 범위

- 중간고사: 1장부터 데이터베이스 설계의 개념적 설계까지, 157문제 풀에서 랜덤 출제
- 기말고사: 논리적 설계 이후, 정규화, SQL, 157문제 풀에서 랜덤 출제

## Local

브라우저에서 `index.html`을 열면 바로 실행됩니다.

## 공개 주소

- GitHub Pages: `https://urusung.github.io/inha-database-quiz/`

## 구성

- `index.html`: 중간고사/기말고사 선택 첫 화면
- `midterm.html`: 중간고사 대비 개념 퀴즈
- `final.html`: 기말고사 대비 개념 퀴즈
- `assets/`: 문제 이미지 자료
- `files/`: 원본 체크문제, 강의 슬라이드, 시험 대비 PDF
