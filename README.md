# inha-database-quiz

인하대 데이터베이스 체크문제, 강의 슬라이드, 시험 대비 PDF(`files/`)를 바탕으로 만든 정적 문제은행 페이지입니다.

- 중간고사: 1장부터 데이터베이스 설계의 개념적 설계까지
- 기말고사: 데이터베이스 설계의 논리적 설계 이후, 정규화, SQL
- 쿼리 암기: DDL, INSERT/UPDATE/DELETE, 집계/GROUP BY, 조인, 부속질의, 집합 연산, EXISTS 예제 SQL
- 작년 기말 제보: 정규화 단계, BCNF, 이상 현상, HAVING, 부속질의 중심 복원형 문제

## Local

브라우저에서 `index.html`을 열면 바로 실행됩니다.

## 공개 주소

- GitHub Pages: `https://urusung.github.io/inha-database-quiz/`

## 구성

- `index.html`: 문제은행 UI, 중간고사/기말고사 범위 분리, 문제 데이터, 채점 로직
- `files/`: 원본 체크문제, 강의 슬라이드, 시험 대비 PDF(로컬 전용, Git 추적 제외)
