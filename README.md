# inha-database-quiz

인하대 데이터베이스 체크문제 이미지와 강의 슬라이드 이미지(`files/`)를 바탕으로 만든 정적 문제은행 페이지입니다.

## Local

브라우저에서 `index.html`을 열면 바로 실행됩니다.

## GitHub Pages

배포 주소:

- `https://urusung.github.io/inha-database-quiz/`

## 구성

- `index.html`: 문제은행 UI, 체크문제/강의 슬라이드 문제 데이터, 채점 로직
- `files/`: 원본 체크문제 및 강의 슬라이드 이미지(로컬 전용, Git 추적 제외)
